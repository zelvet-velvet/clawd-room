## 📐 Rooms in tall panes keep a normal floor, and panes of one window share a scale (Zaviel)
- In a pane taller than ¾ of its width the room is drawn at most ¾ as tall as wide, in the middle of the pane with dark above and below; before, the floor stretched into a long runway.
- Rooms in panes of the same window use one scale (the smallest of their own), so a room with few Clawds no longer looks twice as big as its neighbour.
- Picked from four options (D); whole windows are unchanged. Branch `feat/split-panes` (#15); [[Platforms and Windows]] (Split panes).

## 🚪 A gate between two rooms opens at the same moment on both sides (Zaviel)

## 🔧 Profile update no longer changes the profile after it (Zaviel)
- `python3 setup_profile.py --update` now changes only the Clawd Room profile in Windows Terminal's `settings.json`. Before, it could point the *next* profile (here a Claude Code profile) at the room and give it a 5 pt font, because Windows Terminal saves `commandline` before `guid` and the script only looked after the guid.
- Run `--update` again after moving or re-cloning the repo, as before; if another profile opens a room, put its line back from `settings.json.clawd-room.bak`.
- Branch `fix/setup-profile-update`; [[Platforms and Windows]].
- Checked against a copy of the real `settings.json` (in memory, the file not written): the new code changes only the Clawd Room profile (and nothing when it is already right); the old code rewrote the Claude Code profile. Merged as PR #17.
