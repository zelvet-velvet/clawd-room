## 🏗️ Gates can appear as a construct; gate themes and a settings file (Zaviel)
> [!info] Branch `feat/gate-themes`
- **Construct** (the picked look): a gate is built from its own pieces (boards, posts, lengths of rail, the handle) that fly in from the air under a blue outline and click into place, 1.4 s. The stairs' rail shows at the end.
- **Gate themes**: how a gate appears is a folder `anims/gates/NAME/` (`simple`: the parts come in turn, as before; `construct`). A theme missing a file uses `simple`'s, so a new theme can start with one file. Choose with `--gate-theme NAME`, `CLAWD_GATE_THEME`, or `gate_theme = construct` in `~/.clawd-room/settings.conf` (read again while the room runs).
- A gate part's `x`, `y`, `glow` and `show` keys are drawn in the room now (before only `grow`). The ANIMS tab lists each theme's files and stars the active theme's.
- Preview: the stage page plays the construct like any animation (drag the GROW bar). Not yet: the construct's pieces as authored sprites, the park's own gates, gates leaving. Design: [[Art Data and Editor]].

## ✏️ The stage page: `I` for the pixel art, a part that fits (Zaviel)
> [!info] Branch `feat/gate-themes`
- `i` on a sprite part (the swing's Clawd) opens the pixel editor's picker on the CLAWD tab; Esc brings the stage page back. A part drawn by code (the gates) says so.
- A part as wide as the stage lost the left edge of its yellow frame; the stage now zooms out until the whole frame fits.
- The editor's own window opens at 78% of the screen width (it was 70%), so the picker's frame strip shows four frames.
