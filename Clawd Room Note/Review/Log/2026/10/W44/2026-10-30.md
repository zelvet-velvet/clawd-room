## 🏷️ A callout's type shows its block's state (Zaviel)
- Items with a status or a short detail go in callouts, one per group; tables only for real grids (constants, keys, colours).
- The callout type follows its boxes: `[!todo]` open, `[!done]` done, `[!warning]` blocked, `[!question]` waiting for a decision, `[!failure]` dropped. It changes in the same edit as the boxes.
- Test queue groups now start as `[!todo]` and turn `[!done]` once merged and every test is ticked. Rule in [[LLM Guide]] (Conventions).

## 🧪 How to write a mock program (Zaviel)
- The LLM Guide now says how a mockup program is built: the room's own drawing code on a fixture, at the real window or pane size, enlarged for the sheet, with only the question's part changed in the mock (never in `c/`).
- One build line that links only the current branch's objects, so a leftover from another branch no longer breaks it. Rule in [[LLM Guide]] (Mockups).

## 🪑 Crowded rooms: scattered spots and clusters picked (Zaviel)
- In a small split pane every Clawd went into "+N MORE": the floor was too shallow for the first row of desks. Mockups at the pane's real size led away from rows altogether.
- Picked: **workspaces scattered over the floor, mixed with loose clusters of 2–3**, and smaller, mixed furniture (a narrow desk, a standing desk, a beanbag; a stool, an armchair, a high table; a bench, a tree stump, a picnic blanket; no desks in the park).
- Clawds without a seat get something to do instead of "+N MORE": demolish, start (and put out) a fire, clean up, play catch. Not built yet; what is still open is in [[Rooms and Art]] (hot desking, very small panes, Clawds that react to you).
