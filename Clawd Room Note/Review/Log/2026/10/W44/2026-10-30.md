## 🪟 Rooms in split panes (Zaviel)
- A room can now live in a **split pane** of a Windows Terminal window you work in: it no longer resizes the window or changes the font there.
- Rooms in panes of one window, or a pane next to a room window, get **gates** between them like windows do. Each room finds its own pane from the focus and tells the others its pane in its heartbeat.
- `--list-windows` shows split windows with their panes. Branch `feat/split-panes`; checks T67–T72 in [[Test Checklist]]; how it works in [[Platforms and Windows]].

## 🏷️ A callout's type shows its block's state (Zaviel)
- Items with a status or a short detail go in callouts, one per group; tables only for real grids (constants, keys, colours).
- The callout type follows its boxes: `[!todo]` open, `[!done]` done, `[!warning]` blocked, `[!question]` waiting for a decision, `[!failure]` dropped. It changes in the same edit as the boxes.
- Test queue groups now start as `[!todo]` and turn `[!done]` once merged and every test is ticked. Rule in [[LLM Guide]] (Conventions).
