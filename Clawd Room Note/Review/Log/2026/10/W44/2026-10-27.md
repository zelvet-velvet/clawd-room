## ⚙️ A settings panel on `.` (Zaviel)
- Press **`.`** and a panel opens beside the room (design B, picked 2026-10-20); the room keeps running. **W / S** pick a row, **A / D** change it, **`.`** or Esc close it.
- Four rows: **SPOTLIGHT** (how dark the room is round the picked Clawd), **APPEAR** (the gate theme), **SIZE** (the room size) and **FRAMES** (8 – 30 a second). Each change is saved to `~/.clawd-room/settings.conf` at once and shows at once; editing that file by hand works too.
- A window under 130 columns gets the panel over the room's right side; a short one leaves out the group names. Branch `feat/settings-panel`; checks T63 – T66 in [[Test Checklist]]. Design: [[Interaction]].

## 🌳 The Dev Log's git graph is drawn from git (Zaviel)
- `python3 tools/git_graph.py --write "Clawd Room Note/Review/Dev Log.md"` redraws the graph of merged pull requests: each branch leaves `main` where it really forked and joins where it was merged, so branches open together overlap.
- It draws the last 12 code branches (docs, chore and test ones left out), no commit labels, the PR number in the branch name; `--last`, `--all` and `--labels` change that.
- The graph's colors and branch name chips are set in `mermaid-afterglow.css`; the Days list wraps long titles. Merged in PR #9.

## 🪝 A moved repo no longer blocks Claude Code (Zaviel)
- Re-cloning left the old `hook.py` path in `~/.claude/settings.json`, which blocked every prompt. The LLM Guide and Home now say how to fix it and to run `install_hooks.py --remove` before moving the folder.
